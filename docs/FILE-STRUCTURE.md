# 文件结构

## ROMX 容器结构

```text
┌──────────────────────────────┐
│ ROM payload                  │  原始标准 ROM，不压缩、不修改
├──────────────────────────────┤
│ Metadata JSON                │  UTF-8，嵌入容器本体
├──────────────────────────────┤
│ Cover image                  │  PNG/JPEG/WebP，可选
├──────────────────────────────┤
│ ROMX footer                  │  固定 128 字节
└──────────────────────────────┘
```

读取器必须使用 footer 中的 offset 和 size，不得依赖数据区顺序。

ROM、metadata、cover 区域不得重叠，也不得覆盖 footer。
